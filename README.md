# Bingo Bash

A command-line **Bingo game** in Python for several players. Each player picks how many cards to play, numbers are called at random, and the game ends when all the bingos have been claimed. Cards and the score board are drawn with PrettyTable.

## Running

```bash
pip install prettytable
python3 bingo_application/OopFinalBingoAPP.py
```

## Files

| File | Description |
|---|---|
| `bingo_application/OopFinalBingoAPP.py` | **Final version**: object-oriented game (cards, number calling, scoring) |
| `bingo_application/BingoGame.py` | Earlier procedural version |
| `mainProg.py`, `Game Index.py`, `Get Cards.py`, `Global Call.py` | First prototype, split into modules |
| `b.py`, `ex2.py`, `ey.py`, `ey2.py`, `prac1.py`, `test.py` | Scratch and practice files |
